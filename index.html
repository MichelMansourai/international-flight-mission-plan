Guidelines — How To Use This Mission Plan

Operational disclaimer: this tool is a planning aid for distance/time/fuel arithmetic, checklist tracking, and paperwork organization only. It does not replace official flight planning, NOTAMs, weather briefings, diplomatic clearances, fuel policy, squadron SOPs, or the judgment of the crew. All figures must be cross-checked before flight.

0. What each of the 5 tabs is for

TabPurpose
1. Mission PlanThe live waypoint table — coordinates, distances, dual-speed ETA, fuel, and wind correction for whatever route you enter.
2. Reference LibraryStanding frequency, waypoint-coordinate, and clearance/NOTAM data. Only Rayak (OLRA) baseline data is fixed; everything else is blank and built per mission.
3. Pre-Flight ChecklistA categorized, checkable pre-flight checklist — documents, safety equipment, comms, maintenance, personal items.
4. FAA Flight PlanThe blank official FAA Form 7233-4 (International Flight Plan), embedded for viewing and download.
5. InstructionsThis tab — how to use the tool, plus a field-by-field guide to filling the FAA form.

1. General purpose

This is a generic international flight-plan template for the 18th Squadron — not tied to any specific route or destination. Use it for whichever cross-border mission comes up by entering that trip's waypoints. Add or remove rows freely; every row carries the same live calculations.

2. Filling in the mission header

Enter mission name/callsign, date, departure base, destination, aircraft tail number, PIC, and starting fuel in lbs. Starting fuel drives both fuel-remaining columns, so set it accurately for the actual mission fuel state at engine start.

3. Adding waypoints

  1. Click + Add Waypoint Row for a blank row, or ⧉ Duplicate Last Row to copy the last row's callsign/comm/nav-aid pattern forward (handy when several consecutive CPs share the same controlling agency).
  2. The first row is treated as the origin (Leg Dist = 0) and the last row is treated as the destination. Row order = flight order — use the row buttons to move a row up/down if you insert a point out of sequence.
  3. You can add as many rows as the route needs — there is no fixed limit.

4. Coordinate format

The single Coordinates field auto-detects either of two formats, one per row:

FormatExample
Degrees + decimal minutes (DM)N33 48.44/E035 29.15 — spacing/case tolerant, e.g. n 33 48.44 / e 035 29.15 also parses
MGRS37SFA1234567890 (zone + band letter + 100km square letters + easting/northing digits — 2 to 10 digits, even count, higher digit count = finer precision)

A row highlighted in red under the coordinate box means neither format was recognized — that leg is excluded from the distance/time chain until corrected. Don't mix formats within the same row.

5. What gets calculated automatically

ColumnMethod
Leg Dist (nm)Great-circle (haversine) distance between this row's coordinates and the previous row's coordinates.
Remaining Dist (nm)Sum of all leg distances from this row through to the final (destination) row.
WCA (wind correction angle)If you enter a Wind Dir and Wind Spd on a row, the true course for that leg is computed from its coordinates and a standard wind-triangle solves the correction angle (shown as °L or °R) and the resulting groundspeed.
ETA @ 90 kt / @ 100 ktCumulative flight time from engine start. If wind is entered for a leg, that leg's time uses the wind-corrected groundspeed instead of raw airspeed; legs with no wind entered use still-air 90/100 kt as before.
Fuel @ 90 kt / @ 100 ktStarting fuel − (0.6 × elapsed minutes at that speed's ETA), reflecting a 600 lb/hr average burn.

6. Wind entry

Wind Dir is entered as the direction the wind is blowing from, true (°T) — the standard met/aviation convention. Wind Spd is in knots. Enter both on the row you're arriving at (they describe the leg into that waypoint); leave both blank to plan that leg in still air. The Hdg column stays yours to fill in manually (the corrected heading a pilot would actually fly) — WCA is shown alongside it as a cross-check, not an auto-fill, since true/magnetic variation isn't modeled here.

7. Taxi allowance

5 minutes is automatically added at the first row (taxi-out) before the aircraft starts covering distance, and 5 minutes is automatically added at the last row (taxi-in / shutdown) after the final leg. Both are baked into the ETA and fuel columns already — no manual adjustment needed.

8. Fuel assumption

Fuel burn is a flat average of 600 lbs/hour across the whole mission, applied independently to the 90 kt and 100 kt time lines (a slower ground speed burns fuel over more minutes at the same hourly rate, so the two fuel columns will differ). Adjust the underlying 600 lbs/hr figure with your squadron's actual type/config burn rate before relying on this for real mission fuel planning.

9. Exporting for the crew brief

Once the table is filled in, click 🖨 Export / Print to PDF and choose "Save as PDF" in the print dialog. This produces a static, non-fillable PDF snapshot of that mission's plan (including this guidance page) — readable in any PDF viewer and printable for the cockpit.

10. Reference Library — search, use-in-plan, and clearances

Each of the three Reference Library tables (Frequencies, Waypoint Coordinates, Route Clearances/NOTAM Refs) is collapsed by default — click its title bar to expand. Each has its own search box that filters as you type. On the Waypoint Coordinates table, the → button drops that row straight into the mission plan above, just before the destination row. All three sections still print/export with the rest of the page even while collapsed.

11. Save / Load a mission as a file

💾 Save Mission (JSON) downloads everything currently on the page — mission header, waypoint rows, reference tables, and the pre-flight checklist state — as a single small file you can keep, email, or hand off. 📂 Load Mission (JSON) loads one of these files back in, replacing the current page contents. This is how a mission plan survives closing the browser tab, since the page itself does not save anything on its own.

12. Pre-Flight Checklist (Tab 3)

Five categories — Documents & Clearances, Safety & Emergency Equipment, Communications & Navigation, Maintenance & Aircraft, and Personal & Crew. Tick items off as completed; use + Add Item under any category for anything mission-specific not already listed. This list is a starting point drawn from the FAA international flight plan's supplementary-information requirements (endurance, persons on board, radio, survival equipment, jackets, dinghies, aircraft markings, remarks, pilot-in-command) plus standard cross-border ops items — it is not a substitute for squadron SOP or the official checklist for your aircraft type.

13. FAA Flight Plan (Tab 4)

Tab 4 embeds the blank, official FAA Form 7233-4 (International Flight Plan) so it's always on hand with the rest of the mission package. Click ⬇ Download FAA Form 7233-4 (PDF) to save a copy, or view it directly in the embedded frame. The form itself is static (not auto-filled from this tool) — fill it by hand or in a PDF editor using the field guide below.

14. Filling out FAA Form 7233-4 — field guide

Condensed from the FAA's official instructions for Form 7233-4. This covers the fields you'll actually touch for a squadron international flight; consult the full FAA instructions document for edge cases (PBN codes, ADS-C, Data Comm, etc.) that don't typically apply to a straightforward VFR/IFR cross-border hop.

ItemFieldWhat to enter
7Aircraft IdentificationRegistration number (no hyphens/spaces) or an approved company/organizational designator + flight number. e.g. N235RA, BONGO33.
8aFlight RulesI for IFR, V for VFR. A composite flight (IFR then VFR or vice versa) needs two separate flight plans — one per rule set.
8bType of FlightM for Military (most applicable here). Others: G-General Aviation, S-Scheduled, N-Non-scheduled, D-DVFR, X-Other.
9Number / Type / Wake Turbulence Cat.Number of aircraft (if >1), the 2–4 character ICAO aircraft type designator (use ZZZZ + Item 18 TYP/ if none exists), and wake category: H-Heavy (≥300,000 lb), M-Medium (15,500–300,000 lb), L-Light (≤15,500 lb).
10EquipmentNavigation/comm/approach capability codes (10a) and transponder/ADS-B/surveillance codes (10b). S in 10a = Standard (VHF, VOR, ILS) — usually the simplest correct entry. N if none of that equipment is fitted.
13Departure Aerodrome / TimeFour-letter ICAO identifier (e.g. OLRA for Rayak) and departure time in 4-digit UTC.
15Cruising Speed / Level / RouteTrue airspeed as N+4 digits (e.g. N0090 for 90 kt) or Mach as M+3 digits; requested altitude as A+3 digits (e.g. A080) or flight level as F+3 digits; then the route as a sequence of fixes/waypoints separated by DCT (direct) or published airway identifiers.
16Destination / Total EET / AlternateFour-letter ICAO identifier for destination, total estimated elapsed time (HHMM) — this is exactly what Tab 1's Total Time card gives you — and an alternate aerodrome if applicable.
18Other InformationAny of the coded fields that apply: DOF/ date of flight (YYMMDD) if not today, STS/ special handling (e.g. STATE for military/customs/police service), RMK/ free-text remarks, REG/ aircraft registration if RVSM, OPR/ operator if not obvious from Item 7.
19-E/EnduranceFuel endurance in hours and minutes — read this straight off Tab 1's Fuel Remaining columns at your planned cruise speed.
19-P/Persons on BoardTotal souls on board (3 digits), or TBN if not yet known.
19-R/Emergency RadioCross out UHF/VHF/ELT not carried — leave the ones that are.
19-S/Survival EquipmentCross out Polar/Desert/Maritime/Jungle categories not carried — matches the "Survival kit appropriate to route terrain" checklist item on Tab 3.
19-J/JacketsCross out if not carried; otherwise note Light/Fluorescent/UHF/VHF as applicable.
19-D/DinghiesNumber, total capacity, whether covered, and color — matches the "Life raft / dinghies" checklist item.
19-A/Aircraft Color and MarkingsUse the standard color-code abbreviations (e.g. A/W/R/Y = White/Red/Yellow) or plain text.
19-N/Remarks (not for ATC)Survival equipment notes, personal locator beacon info, or a contact for verifying VFR arrival — this section is retained by the filing service, not transmitted to ATC.
19-C/Pilot-in-CommandName and a phone number reachable at ETA, for search-and-rescue purposes.
Item 19 (Supplementary Information) is never transmitted to ATC as part of the IFR message — it's retained by the filing service for search-and-rescue use only. Keep it accurate regardless; it's the information that matters most if something goes wrong.

15. Reset

Reset Table clears all rows and mission header fields back to a blank two-row template (origin + destination) for the next mission. It does not touch the Reference Library, Checklist, or FAA Flight Plan tabs.
